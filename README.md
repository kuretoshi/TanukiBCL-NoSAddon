# タヌキ丼（タヌキのアドオン）

Nebula on the Ship（NoS）に、タヌキのベタクルと連携する役職・モディファイアを追加する開発中のアドオンです。

現在のバージョンは **0.1.0-β4 / Build 43** です。PC版ベタクル3.2.25以降に対応します。Web・モバイルからのホスト中継もベータ機能で、対応するベタクルと全参加者のアドオン更新が必要です。

タイトル画面の右下にタヌキアイコンの問い合わせボタンを追加しました。カーソルを合わせると説明が表示され、クリックすると [問い合わせ用Discord](https://discord.gg/j7grHxTh4H) を開きます。

今後の配布ZIP名はバージョンを含まない `TanukiBCL-NoSAddon.zip` に固定します。バージョンはZIP内の `addon.meta` とGitHubのリリース名・タグで管理します。NoSの `Addons` フォルダーへ配置する際は、旧版の `TanukiBCL-Roles-*.zip` や `TanukiBCL-NoSAddon-*.zip` と重複させず、差し替え前にNoSを終了してください。β3は固定名で再公開しました。β1・β2のファイル名はそのまま維持します。

GitHubでリリースを公開すると、リポジトリSecret `DISCORD_WEBHOOK_URL` の通知先へバージョン・変更内容・ダウンロードリンクを送ります。Webhook URLはソースに含めません。

## 0.1.0-β3：メガホンレーザーの発射時録音再生

チャージ中の本人の声を対応するベタクルがメモリ内に一時録音し、発射時に全員へ距離・壁に関係なく再生します。チャージ中の通常通話は通常の距離設定のままです。最大10秒の録音は発射後に残響を約2.4秒残し、録音ファイルは保存しません。「発射時の録音音声に残響をつける」をオフにすると録音音声を加工せず再生します。チャージ中断・会議・ゲーム終了では録音を破棄し、ミュート・プレイヤー別音量・全体音量を尊重します。各受信者が受信した音声を保持するため、チャージ途中から接続した受信者は接続後の部分のみ再生します。タヌキ丼0.1.0-β3、PC版3.2.25、Web・モバイル版3.17への更新が必要です。

チャージ・発射状態にはshotIdとphaseを追加し、各ゲームの状態ファイルを `megaphone-state-<PID>.json` に分けます。複数起動時も各ベタクルは対応するゲームPIDの状態だけを読みます。コンパイル・型チェック・録音の開始／中断／発射／上限の自動テストは確認済み、複数人の実音声による動作確認は未実施です。

## 開発・検証

NoSを一度起動してアドオンコンパイラと参照情報を生成した後、PowerShellで実行します。

```powershell
dotnet run --project tests/GateTests.csproj
./scripts/validate-nos.ps1 -GameDirectory 'NoSのインストール先'
./scripts/package.ps1
```

パッケージは `dist/` に生成します。ゲーム本体・NoS・ベタクル本体・証明書・ビルド成果物はこのリポジトリに含めません。

## 役職

Web・モバイルの役職マイク連携はホスト中継方式（ベータ）です。ホストのベタクル3.2.24以降、Web・Mobile 3.13以降、全参加者のタヌキ丼0.1.0-β3を使用し、参加者は通常の参加操作だけで自動接続します。証明書登録や接続コードは不要です。ホスト中継の実ゲーム通信は確認済みですが、全端末の組み合わせは未検証です。

開発中の追加仕様：メガホンは能力ON中に死亡すると、死亡直前の本人の声が約2.4秒かけて残響として消えます。能力OFF・電池切れ・切断・役職解除では発生しません。ビビリの残響通信と再生処理を共用し、対応するPC・Web・Android版で再生します。音声の録音ファイルは保存しません。

「ビビリ」：モディファイア。設定した声量に達した瞬間に自滅します。会議中の判定は設定で変更可能です。縦メーターで死亡ラインを表示し、自滅時は対応するベタクルで本人の声の残響を残します。

「メガホンレーザー」：インポスター陣営。能力ボタンでチャージを開始します。移動不可、マウスで照準変更可能。制限時間内に声のエネルギーを蓄積し、時間終了時に方向と太さを固定して自動発射します。チャージ中の予告ビームが蓄積に応じて太くなります。
蓄積は減らず、最大になっても制限時間まで待ちます。未接続・無言でも極細ビームを発射します。通信途絶は既存の蓄積を保持し、追加蓄積を停止します。会議・死亡・役職解除で蓄積を破棄し、キャンセルします。
ビームは壁貫通、前方への攻撃判定に距離上限なし、持続5秒（ローカルUchuAddon 1.3.7のノヴァの初期仕様に準拠）。描画はマップ全域を覆う150ユニット、メガホンとビームは自作のコード描画です。

部屋主の設定：発射方向（自由／左右／上下左右）、発射クールダウン、チャージ時間、最小・最大幅、満充電に必要な声量蓄積量、蓄積開始音量、最大蓄積速度となる音量、フレンドリーファイア、通常キルの有無。
初期値：30秒クールダウン、3秒チャージ、幅0.05～3.5、最大声量1.5秒分で満充電、蓄積開始-45dBFS・最大速度-12dBFS、通常キルON・フレンドリーファイアOFF。フレンドリーファイアONでも自分自身は対象外です。

「おしゃべり」：モディファイア。設定した秒数発言しないと自滅します。会議中の判定は設定で変更可能です。

「メガホン」：クルーメイトの通常役職。専用ボタンでON/OFFを切り替え、使用中だけベタクルの通常の声の範囲に初期値+5を追加します（ベタクル標準5.32なら10.32）。初期バッテリー100%、満充電で初期値60秒使用可能。使用中は無言でも消費し、電池切れで停止します。タスク1個完了で初期値10%回復、上限100%。追加範囲0～30、使用時間5～180秒、回復量0～100%を部屋主が変更できます。会議・死亡・解除でOFF、会議で残量はリセットされません。声の加工はせず、通常の壁・通信妨害・ミュート設定を維持します。レーザーと同じ外形にミント色の縁と3本のバッテリー表示を加えた専用アイコンを使用します。

## パッケージと導入

`powershell -File scripts/package.ps1` でメタデータの版に対応するZIP（現在 `dist/TanukiBCL-Roles-0.8.0.zip`）を作成します。
対応するNoSのゲームフォルダー内の `Addons` に配置します。参加者全員に同じAddonが必要です。
NoS起動時に `Scripts/*.cs` がコンパイルされます。メガホン／メガホンレーザーは役職設定、ビビリ／おしゃべりはモディファイア設定で割り当ててください。旧版と新版を同時にAddonsへ入れないでください。UchuAddonへの依存はありません。

導入先は `C:/Program Files (x86)/Steam/steamapps/common/Among Us NoS/Addons`。ZIPの更新後にNoSを再起動してください。
開発版ベタクルは `D:/VSCode/BetterCrewLink` で `npm run dev` を実行すると起動できます。既に起動中のベタクルがある場合は終了してから起動してください。

## ベタクルとの通信仕様（v1）

本人に役職が付与されると、`%LOCALAPPDATA%/TanukiBCL/NoS/voice-role.json` に `protocol`, `role`, `playerId`, `pid`, `port`, `token` を公開します。
ローカル専用のUDPポートを役職付与ごとに割り当て、解除時に閉じます。ベタクルはNoSのプロセスIDとプレイヤーIDが一致する場合のみ送信し、ファイルが消えたら停止してください。

20HzでASCIIの `TBCL1|token|sequence|unixMilliseconds|rms|active` を `127.0.0.1:port` に送ります。
`sequence` は同じtoken内で増加する非負整数、`rms` は0～1の線形RMS、`active` は実際にマイク送信可能なら1、ミュート/PTT未押下/入力停止なら0です。
RMSはベタクル側の音量ゲイン・役職音声エフェクト適用前に測ります。自動ゲイン等のマイク処理の影響は受けるため、マイク別の校正は今後必要です。
150msより古い通知、token不一致、不正値、順序逆転を拒否します。サンプル間隔が150msを超えると継続判定をリセットします。
tokenは試合をまたぐ通知の誤適用を防ぐためのものです。同一PC上の改造クライアントの不正を防ぐものではありません。

## 検証

`dotnet run --project tests/GateTests.csproj` で継続時間・瞬間音・無音・ミュート・不正値・通信途絶・会議後のリセットを検証します。
ローカルUDPでの受信・古い通知の拒否・セッション照合・解放も検証します。実際の音量役職がアクティブな間はテストを実行しないでください。
Addon全体のコンパイル確認には、起動済みNoSのDLLが必要です。
`dotnet build TanukiBCL.Roles.csproj -p:AmongUs="ゲームのパス" -p:NoSPluginDir="Nebula.dllのフォルダー"` で確認できます。NebulaAPI.dllはゲーム直下のNebulaLibsを参照します。
ベタクル側では `node scripts/test-nos-voice-role.mjs`、`npm run typecheck`、`npm run build` を実行します。
実機で確認が必要な項目：Addon読み込み、設定表示、割り当て、死亡RPC、会議中停止、ゲーム終了と役職変更時の解放。

### 0.3.0: 声によるチャージ予告

チャージボタンに声の蓄積量をパーセントとゲージで表示します。Dancerの進行量表示を参考にした独自タイマーです。
チャージ中の声をタヌキのベタクルでうねる声に加工し、蓄積量に応じて届く半径を2から最大20ゲーム単位まで広げます。最大半径は部屋主が2〜40で設定できます。境界では音量を滑らかに下げ、壁越しにも予告が届きます。プレイヤー別ミュート・音量、全体音量、ジャミングは有効です。
制限時間後の自動発射、無言中の蓄積維持、ビーム幅の仕様は継続します。発射・キャンセル・会議・死亡時に加工と拡張を解除します。
各NoSクライアントがゲームRPCで受けたチャージ状態を `%LOCALAPPDATA%/TanukiBCL/NoS/megaphone-state.json` に出力し、ベタクルはPID一致かつ500ms以内のデータのみ読みます。音声を聞く参加者にも、このアドオンと今回のベタクル修正版が必要です。
新ZIPは `dist/TanukiBCL-Roles-0.3.0.zip`。旧版と同時にAddonsへ置かず、ゲームを再起動して読み込んでください。
通信・範囲・加工解除の自動テストとNoS実コンパイラで検証済みです。複数人での実際の聞こえ方は要確認です。

### 0.4.0: おしゃべり

クルー役職「おしゃべり」を追加しました。初期値は無言20秒で死亡、検知しきい値-35dBFS、会議中の計測ONです。部屋主は死亡までの時間（5〜120秒）、検知しきい値（-60〜-5dBFS）、会議中の計測を設定できます。
検知しきい値以上の声でタイマーがリセットされます。会議中の計測OFFでは会議開始・終了でリセット、ONでは会議でも続行します。追放演出・イントロ中は停止します。会議中の死亡にはNoS標準のMeetingKillを使用します。
本人の画面に残り秒数・停止中・ベタクル未接続を表示します。接続途絶時は残り秒数を維持して停止し、再接続後に再開します。接続中のミュート、プッシュトゥトーク未押下、スピーカーミュート、ジャミングによるマイク遮断は無言として扱われます。
ベタクルはおしゃべりにだけ会議中も音量・無音のハートビートを送ります。ビビリとメガホンの会議中の判定は従来通り停止します。
新版は `dist/TanukiBCL-Roles-0.4.0.zip` です。NoSを終了してから、`scripts/install.ps1 -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Among Us NoS"` を実行すると旧ZIPをバックアップして新版へ差し替えます。
タイマー・切断・ミュート・会議向けUDP通信の自動テストとNoS実コンパイラで検証済みです。ゲーム内のHUD表示・会議死亡と投票の実動作は未検証です。

### 0.4.1: 起動時のRPC初期化エラー修正

NoSのRPCシリアライザーは8項目以上のValueTupleのRestフィールドに対応していません。メガホンの座標を入れ子の2項目タプルにまとめ、外側を7項目へ変更しました（RPC名V3）。0.4.0の「Can not Tuple Constructor」起動エラーを修正し、実ゲームでメインメニューへの到達を確認済みです。参加者全員で同じ新版を使用してください。

### 0.4.2: 未接続表示のちらつき抑制

おしゃべりの接続表示は、最後の有効な音量データから1秒までは接続中として扱うよう変更しました（従来150ms）。無言タイマーの加算条件は150ms以内の有効データ間隔のままで、接続表示の猶予中にも未観測の時間を加算しません。1秒を超える通信途絶は未接続と表示します。自動テストと実NoSコンパイラで検証済みです。
