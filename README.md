# タヌキ丼（タヌキのアドオン）

**TanukiBCL-NoSAddon** は、Nebula on the Ship（NoS）に、タヌキのベタクルと連動する役職・モディファイアを追加する非公式アドオンです。無料で配布しています。

## 導入方法

1. [Releases](https://github.com/kuretoshi/TanukiBCL-NoSAddon/releases)から `TanukiBCL-NoSAddon.zip` をダウンロードします。
2. NoSを終了し、ゲームフォルダー内の `Addons` にZIPを解凍せず配置します。
3. 同じアドオンの旧ZIPが残っていれば、`Addons` の外へ移動します。旧版と新版を同時に入れないでください。
4. NoSと対応するタヌキのベタクルを起動します。
5. 部屋主が役職設定・モディファイア設定で割り当てます。

更新時もNoSを終了してからZIPを差し替えてください。声量設定は、設定画面のマイクテストで普段の声と大きな声を確認して調整できます。

## 配布版の役職・モディファイア

役職設定一覧の説明枠右上には、タヌキ丼の役職であることを示すたぬきのマークを表示します。Discordボタンと同じアイコンを使い、マウスを当てると提供元の案内が表示されます。

| 名前 | 種類 | 能力 |
| --- | --- | --- |
| ビビリ | モディファイア | 設定した声量に達すると即座に自滅。声量を縦メーターで表示し、自滅時に本人の声の残響を残します。会議中の判定は設定可能です。 |
| おしゃべり | モディファイア | 設定時間にわたり発言しないと自滅。発言を検知すると無言タイマーをリセットします。会議中の判定は設定可能です。 |
| メガホンレーザー | インポスター陣営の通常役職 | 声でチャージし、照準方向へ壁を貫通するレーザーを発射します。チャージ中の声を発射時に全員へ再生します。 |
| インタビュアー | クルーメイト陣営の通常役職 | 自分と視界内の声を録音し、会議中に全員へ再生します。録音時間・クールダウン・会議ごとの再生回数を設定できます。 |
| ボイスジャミンガー | インポスター陣営の通常役職 | 近くの相手の声を次の会議だけ強制ミュートまたはローパスにします。会議中には全員の声のピッチを設定秒数ランダムに変えられます。通常キルも可能です。 |
| ダイイングボイスメッセージ | モディファイア | 死亡後の声をその場に残し、近づいた生存者へラジオ風に再生します。生存中は本人も付与を自覚できません。 |
| メガホン | クルーメイト陣営の通常役職 | 使用中だけ声の届く範囲を広げます。バッテリーを消費し、タスク完了で回復します。 |
| スーパーヒーロー | クルーメイト陣営の通常役職 | ボタン使用後「変身」と話すと、設定時間だけ専用衣装・無敵・キル能力を得ます。クルーを狙うと誤射で自滅します。 |
| イーヴィルヒーロー | インポスター陣営の通常役職 | 変身中だけキル可能。専用衣装と闇の演出で変身し、スーパーヒーローからのキル以外には無敵です。 |
| NGワード | モディファイア | ホストの外部リストから全参加者へワードを配布。自分の画面に表示され、そのワードを認識すると即死します。会議中の判定は設定可能です。 |

ヒーローの変身時間・クールダウン・変身中の名前非表示などを設定できます。両ヒーローは互いのキルを防げず、自殺・誤射・追放も防ぎません。詳細は[ヒーロー役職](docs/heroes.md)を参照してください。

NGワードを全員へ配るには、ロビーのNGワード設定で全員配布をオンにします。ゲームフォルダーの `TanukiBCL/NGWords.txt` は初回起動時にテンプレートから作成します。UTF-8で一行に一語を記載し、`表示名|読み方` も指定できます。[設定と記載例](docs/ng-word.md)を参照してください。

### メガホンレーザー

専用ボタンでチャージを開始します。チャージ中は移動できず、マウスで照準を変更できます。声の蓄積量に応じてビームが太くなり、チャージ時間終了時に方向と太さを固定して自動発射します。無言・未接続でも最小幅のビームを発射します。会議・死亡・役職解除でチャージを中断します。

初期値はクールダウン30秒、チャージ3秒、ビーム幅0.05〜3.5、持続5秒です。部屋主は発射方向、クールダウン、チャージ時間、幅、声量の蓄積条件、フレンドリーファイア、通常キル、効果音などを設定できます。

チャージ中の通常通話の距離は通常設定のままです。発射時にはチャージ中の声を距離・壁に関係なく再生します。録音は最大10秒で、残響は約2.4秒。「発射時の録音音声に残響をつける」をOFFにすると加工せず再生します。途中から接続した参加者には、接続後に受信した部分だけが再生されます。

### メガホン

専用ボタンでON/OFFを切り替えます。初期値は通常の声の範囲に＋5、バッテリー100%、満充電で60秒使用可能、タスク1個で10%回復です。追加範囲・使用可能時間・回復量を設定できます。使用中は無言でも消費します。会議・死亡・役職解除でOFFになり、会議でバッテリーは回復しません。

メガホン・インタビュアーには、それぞれ「通信妨害中は能力を使用不可にする」設定があります（初期値オフ）。オンの場合、メガホンは拡声を停止し、残りの電池を保持します。インタビュアーは途中までの録音を保存して停止します。修復後は手動で再使用します。会議中の録音再生はこの設定の対象外です。

## 問い合わせ

設定→NoSの「タヌキ丼への問い合わせ」から件名・内容を入力し、公開への同意後にログ付きGitHub Issueを送信できます。送信先は本アドオンの公開リポジトリです。添付は `NebulaLog.txt` と `BepInEx/LogOutput.log` の末尾各256 KiBまでで、一般的な認証情報・ユーザーパスを伏せます。完全な匿名化は保証できないため、送信前にログ確認画面で内容を確認してください。送信後にIssueを開けます。Discordフォーラムへの反映には数分かかる場合があります。

ビビリのメーターは会議中の判定がONなら会議中も表示し、OFFなら非表示になります。

### その他

- メガホンは能力使用中に死亡した場合、死亡直前の声を約2.4秒の残響として再生する処理を追加しています。

新しいHUDの実ゲーム表示や複数人での聞こえ方は、引き続き確認が必要です。

## Web・モバイル音声連携（ベータ）

Web・モバイル版のマイク情報を、ホストのベタクル→ホストのNoS→対象プレイヤーのNoSへ中継し、各役職の声量判定へ反映します。参加者は通常の音声参加操作で接続できます。

ホストの対応するPC版ベタクルと、全参加者のアドオン更新が必要です。ホスト中継の実ゲーム通信は確認済みですが、すべての端末・環境の組み合わせを検証したわけではありません。

## 音声の扱い

声量判定にはマイクの音量情報を使います。

「変身」とNGワードの認識は日本語のローカル音声認識モデルを使います。PC通常版・Lite版・.NET版は各自のマイクを自分のPCで認識し、Web・モバイル参加者の音声だけホスト側で認識します。外部の音声認識サービスへ音声や文字起こしを送信・保存しません。聞き間違い・取りこぼしは発生し得ます。

メガホンレーザーの録音再生や死亡時の残響は、対応するベタクルが音声をメモリ内で一時的に保持して処理します。この役職機能は録音ファイルを保存しません。レーザーのチャージ中断・会議・ゲーム終了時には録音を破棄します。再生時はミュートやプレイヤー別音量・全体音量の設定を反映します。

## 開発・検証

「[インタビュアー](docs/interviewer.md)」「[ボイスジャミンガー](docs/voice-jamminger.md)」の仕様と対応版、および[リリース時の記載方針](docs/releasing.md)を参照してください。

NoSを一度起動し、アドオンコンパイラと参照情報を生成してから、リポジトリのルートで実行します。.NET SDKなどの開発環境が必要です。

```powershell
dotnet run --project tests/GateTests.csproj
./scripts/validate-nos.ps1 -GameDirectory 'NoSのインストール先'
./scripts/package.ps1
```

ZIPは `dist/TanukiBCL-NoSAddon.zip` に生成します。開発版の導入は、NoSを終了してから次のコマンドで行えます。既存ZIPはバックアップされます。

```powershell
./scripts/install.ps1 -GameDirectory 'NoSのインストール先'
```

アドオンのスクリプト・翻訳・リソースは `addon/`、自動テストは `tests/`、ビルド・導入用スクリプトは `scripts/` にあります。ゲーム本体・NoS本体・ベタクル本体・証明書・生成したビルド成果物は配布ソースに含めません。

検証にはNoSの公開APIと、実ゲームが生成する参照情報を使用します。UchuAddonの画像・音声・エフェクト素材やソースのコピーは含みません。
