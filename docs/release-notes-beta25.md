タヌキ丼 0.1.0-β25 / Build 64

- 新役職「ソナーマン」を追加しました。クルーメイト・マッドメイト両対応。設定した範囲の発話を壁越しでも探知し、その方角を円周上の丸で表示します。一周ごとに更新し、声が聞こえる範囲や音量は変えません。効果時間・クールダウン・検知範囲・一周時間を設定できます。
- レーダーは半透明の緑の円盤、同心円、方位目盛り、残光を引く走査光で表示します。発動時と一周ごとに、使用者だけへソナー音を鳴らします。会議や能力終了で表示・音ともに停止します。
- 「音声認証」を通常のショートタスク候補に追加しました。「各種設定 → 音声認証タスク」で有効にできます（初期Off）。通信室などの専用通信装置で指定された単語を読み上げると進みます。必要な単語数は1〜5語から設定でき、閉じても進捗を保持します。
- 音声認証の単語リストはファイルの参照・テンプレート保存・現在の設定保存に対応しました。ホストが選んだ出題を共有するため、参加者側のファイル配置は不要です。
- ボイスストーンの認識結果の確認画面を廃止し、認識した単語をその場へ自動設置するようにしました。対応ベタクルでは発話の区切りで認識を始め、録音時間の上限を待ちません。認識失敗後のクールダウンは0.5秒です。

NoS Snapshot 26.11.27a以降が必要です。PC通常版・Lite版3.2.72、Tauri版3.2.72-tauri-beta.1、.NET版3.2.72-net-beta.1へ更新してください。Web・モバイル版3.69はそのまま利用でき、ホスト側のPC版を更新してください。共有音声モデルの再導入は不要です。

NoSコンパイルと、ソナーの周回・範囲・中断・効果音、タスクの出題・進捗・再開・単語ファイル、ボイスストーンの即時設置・重複拒否の自動テストを実施しています。新版の物理マイク・多人数接続での実ゲーム検証は含みません。
