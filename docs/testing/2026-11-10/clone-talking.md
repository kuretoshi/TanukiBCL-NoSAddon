# クローンの発話表示の偽装（2026-11-10）

## 変更

ロビー設定「クローンの発声を本人の発話表示に偽装する」を追加。初期値オン。クルーメイト／マッドメイト共通。各端末で聞こえる録音の再生位置から短いPCM窓を判定し、本人の枠を光らせる。実マイクのVAD・サーバー送信とは分離した。オフでは音声はそのまま再生する。旧データで設定が省略されていた場合は偽装しない。

## 確認済み

- NoS: nos_check 成功、96ソース、エラー・警告なし。既存GateTests完走。
- PC通常版／Lite共通とWeb／モバイル: 既存test-parrot.mjsを拡張。10秒の合成PCM録音、無音区間、再ループ、範囲外、本人が遠方、受信音量ゼロ、出力停止、会議、再録音、消滅、オン／オフ、旧データ省略と不正型を確認。通常のオウムの0.5／1.5／3／5秒テストも成功。
- PCとWeb／モバイルの実際のコントローラー関数を呼び、クローンの声で本人の表示が変わること、実VAD状態を変更しないことを確認。
- PC: 型チェック成功、220 TS/JSファイルのネスト最大3以内。
- Web／モバイル: TypeScript型チェック成功。Androidのネイティブ発話表示にも表示専用イベントを接続。
- .NET: clone-self-test、parrot-self-test、policy-self-test成功。音声ミックスと表示状態、無音、オン／オフ、音量、範囲外、出力停止、会議、再録音、旧データ省略、Web／モバイル連携を確認。所有者がベント内・変装中・本人の生音声が範囲外でも、聞こえるクローンの枠を表示するOverlaySelectionも確認。
- .NET Client: ビルド成功、警告・エラーなし。voice-view-self-test／overlay-self-test成功。今回触ったC#11ファイル＋CloneRole.csはネスト3以内。
