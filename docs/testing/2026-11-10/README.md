# 役職検証（2026-11-10）

発声なしで、新役職3種のNoS実行確認と、既存の音声役職を含む自動テストを実施した。実マイク認識や複数人の聴感まで合格としたものではない。公開リリース・バージョン更新は行っていない。

## 実行環境と方法

- Among Us v19s / NoS v3.7.1.1 / UchuAddon v1.4.0、1人のフリープレイ。
- 既存のPC通常版・Lite共通、Web／モバイル、.NET開発環境を再利用した。依存や音声認識モデルの全体コピーは作成していない。
- ゲーム内確認は最新の開発アドオンを配置して実施。別のローカルテスト拡張で、公開APIによる配役と状態採取を行った。テスト拡張はホストかつ1人のフリープレイだけで動く。
- ベタクルのマイクをミュートし、声堅めには認証済みアドオンTCP接続から認識結果を模した単語を送った。オウムにも録音開始要求を送った。これは実際の発声・単語認識の検証ではない。

## 自動テスト

以下は今回実行し、すべて成功した。

- アドオン全体のGateTests：ヒーローの変身時間・失敗時処理・個人文言、NGワードのファイル操作、インタビュアー、ボイスジャミンガー、メガホン、音声ブリッジ・認証・接続互換など。
- 声堅め：単語の検証、文字数に比例した幅、期限切れ・再送・中断。
- オウム：設置上限1・5、録音時間0.5・1.5・3・5秒、最新5件、範囲への進入、会議・撤去。
- アドオンTCP接続：認証・フレーミング・再送防止・登録。
- NGワード割当：2〜24人、各100シード、入力・切断処理。
- NoS AddonData：186状態の符号化、無効なタグ・ビット、公開イベントAPIと未対応環境。
- PC／Lite共通とWeb／モバイル：声堅め連携、音声認識の分担、耳の音声ポリシー、オウムのテスト用PCM録音・再生、インタビュアー、ボイスジャミンガー、ヒーロー衣装の音声エフェクト除外。
- .NET：音声認識の分担、耳、オウムの各自己テストと、既存役職・無線・遮音などの音声ポリシー全体テスト。出力は[net-policy.log](net-policy.log)。
- NoS開発キット：本体93ソースとテスト拡張1ソースのコンパイルで、エラー・警告なし。

PC／Lite・Web／モバイルのPCM／ポリシーテストと、.NETの自己テストは実施したが、各版をそれぞれ複数端末で接続する実プレイは行っていない。テスト用音声の成功は、実際の声が他の端末で聞こえたことの代わりにはならない。

## 検出事項と終了後の状態

- PC開発環境のNoS読み取り補助プログラムが古く、起動時に読み取りエラーが出た。既に更新済みだったソースからx64補助プログラムだけを再ビルドし、NoSの状態とオウム役職をベタクルが取得できることを確認した。役職の本番ソースを修正する必要は生じなかった。
- NoSログにPlumberや実績などの既存エラーがある。以前のログにも存在するもので、新役職に起因する例外は今回観測していない。
- 直前の実装時に追加部分の制御ネスト3以下を確認済み。.NET全体には未変更の `ClientSettingsStore.Load` の深さ4が1件残る。今回、全体のネストがすべて3以下になったとはしていない。
- 指定どおりCtrl+F5で廃村し、「終了」から退出した後にNoSを閉じた。今回起動した開発版ベタクルも終了した。
- ゲームのAddonsには検証した開発版アドオンを残した。検証専用ZIPはAddonsから外し、`dist/local-tests/TanukiBCL-LocalRoleTests.zip` に移動した。本体の配布ZIPにはテスト拡張を含めていない。
- 元のインストール済みZIPは複製せず、`dist/installed-backups/[M59]TanukiBCL-NoSAddon-before-role-tests.zip` に移動して1つだけ保持している。

録音を伴う新役職は、アドオンだけでなく今回の変更を含むベタクル開発版との組合せで検証した。従来の公開版ベタクルとの組合せを動作保証するものではない。保留中のクローンは今回の対象外。
