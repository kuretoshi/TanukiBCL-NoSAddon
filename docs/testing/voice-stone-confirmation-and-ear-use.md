# ボイスストーンの認識確認と耳の使用ボタン

2026-11-19。公開前のローカル修正。Tauriのパス・プルダウン修正とは別に、NoSアドオン側で扱う。

ボイスストーンは音声認識結果を即座に設置せず、本人の確認画面へ表示する。「設置」「録音し直す」「キャンセル」を選択でき、確認期限は20秒。「設置」を押した時点の足元に石を作る。現在の日本語軽量モデルの辞書には「インポスター」がなく、「ポスター」等になることがある。確認の追加は誤った文字の自動設置を防ぐ変更であり、モデルの語彙や認識精度そのものは変わらない。

候補をRPCで共有し、確定前の設置、候補と異なる文字、重複・古い録音結果、期限切れを拒否する。再録音は新しいシーケンスを使い、追加クールダウンを課さない。会議・死亡・切断・役職解除で確認を閉じる。画面を開いた際のCanMove制限と試合中の利用可否を分け、表示した本人も確定できるようにする。音声認識の準備状態は確認中も維持する。

設置SEは新規の短い合成音。実際に石が作られた時だけ一度再生し、距離で減衰させ、ゲームのSE音量とミュートを反映する。クリップは初回のみ生成して再利用し、各石のAudioSourceは石と同じ寿命で破棄する。

壁に耳ありはマップ上のクリック判定を外し、近くの使用可能な耳がある間だけ「使用」能力ボタンを表示する。複数の場合は壁に遮られていない最も近い耳を選ぶ。使用中は「解除」を表示し、停止するまで移動不可。設置のクールダウンと使用・解除は独立する。

自動確認：`dotnet run --project tests/VoiceStone/VoiceStoneTests.csproj --no-restore`。候補確認、再録音、取り消し、通信重複・期限切れ、壁判定を含む耳選択、SEの有限値・振幅・減衰を確認する。`nos_check`で実際のNoS参照を使用してコンパイルする。物理マイクでの認識精度、実ゲームの確認画面・SE・ボタン操作は別途確認が必要。

## 2026-11-21 確認画面が開かない問題

NoS v3.7.2.1 / Among Us v19sの一人フリープレイで、ローカルUDPから合成単語「猫」を送信。request一致・待機中・利用可能・期限内・単語検証成功の状態まで到達したが、Previewに入らず期限切れになることを再現した。外側の役職に生成されたRPCコールバックから、Abilityのprivateメソッドを呼んでいた。NoSのhidden-memberコンパイルは通るが、実行時のアクセス例外をRPCRouterが捕捉して破棄する。Preview、Retry、Cancelを既存のBegin、Placeと同じinternalに変更した。

修正後は同じUDP経路から「猫」→確認画面→「録音し直す」→別requestの「犬」→「設置」で、足元の石とPlacedログを確認した。TCP AddonLinkでも「猫」→確認画面→「キャンセル」で画面が閉じ、石を生成しないことを確認した。合成結果のため、マイク入力・認識精度の検証を代用するものではない。テスト用接続とタイマーは終了し、NoSはCtrl+F5で廃村してから終了した。

認識期限は能力開始時にUTCで一度記録し、ポーリングによる丸め変動をなくした。Tauri側では別に、期限更新を認識器の識別子に含める問題を修正した。旧コードで安定期限では結果が出るが±1ms更新で出なくなることを録音済みテスト音声で再現し、修正後は両条件で同じ結果が返ることを確認済み。
