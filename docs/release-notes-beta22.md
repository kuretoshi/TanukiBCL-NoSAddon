タヌキ丼 0.1.0-β22 / Build 61

- bitキャラクターの全段階を通常クルーの本体アニメーションに合わせました。2〜8bitは左右交互の足運びを4姿勢でカクカク表示し、16・32bitは通常の12コマに追従します。
- 足元の影も通常本体の描画を使うように変更し、独自の上下動や影による位置ずれ・歩行中の影の消失に対処しました。会議のプレートにも同じbit表現を適用します。
- 64bit段階を削除しました。進行は「2→4→8→16→32→元の姿」となり、継続時間は5段階それぞれで設定できます。2bitは白黒、4bit以降は選択したプレイヤーカラーを使用します。
- ロビーの必要バージョン案内を、実際のバージョン判定基準と一致するよう修正しました。

対応：通常版・Lite版3.2.66以降、Tauri版3.2.66-tauri-beta.1以降、.NET版3.2.66-net-beta.1以降、Web・モバイル版3.63以降。ホストも対応版をご使用ください。Tauri版は検出バージョンの送信が修正された3.2.66-tauri-beta.3を推奨します。今回の変更に伴うベタクル各版の追加更新はありません。

検証：NoSコンパイルと、5段階の歩行・描画条件・会議用マスク・ヒーロー衣装との優先順位・衣装復元・音声連携の段階遷移・描画リソース解放の自動テストを通過しています。今回の修正後の実ゲーム画面・GPUでの表示確認は未実施です。
