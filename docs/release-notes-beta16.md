# タヌキ丼 0.1.0-β16

### 新役職：スーパーヒーロー／イーヴィルヒーロー

能力ボタンを押して「変身」と話すと、専用コスチュームと光／闇の演出で変身します。変身中だけ無敵とキル能力を使えますが、敵対するヒーローのキルは防げません。スーパーヒーローがクルーを狙うと自滅します。変身時間・クールダウン・変身中の名前非表示を設定できます。

歩行・梯子昇降用の衣装と、両ヒーローの変身SE・専用変身アイコンを追加しました。キルボタンは既存のキルアイコンを使用し、スーパーヒーローは「正義執行」と表示します。

### 新モディファイア：NGワード

ホストの `TanukiBCL/NGWords.txt` から全参加者へワードをランダムに配り、自分のワードを画面上に表示します。発言が認識されると即死します。リストのテンプレートを同梱し、読み方の指定にも対応しました。全員配布と会議中の判定を設定できます。

### 音声認識と対応版

NGワードと「変身」は、PC参加者が各自の端末で認識し、Web・モバイル参加者のみホスト側で認識します。外部の音声認識サーバーは使用しません。

- PC通常版・Lite版：**3.2.47以降**
- .NET版：**3.2.47-net-beta.1以降**
- Web・モバイル版：**3.39以降**（ホスト側も対応版が必要）

全参加者のアドオンとベタクルを合わせて更新してください。配布ZIP名は `TanukiBCL-NoSAddon.zip` です。

音声認識には聞き間違いが生じる場合があります。フリープレイでの表示・判定結果の連携とビルド／自動テストは確認済みですが、複数端末での新機能の実音声・大人数時の負荷は引き続き確認が必要です。
