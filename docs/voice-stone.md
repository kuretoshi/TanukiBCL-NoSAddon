# ボイスストーン（β19）

キル能力のないマッドメイト役職。見かけのクルー人数・クルー側の配役枠に入り、インポスター勝利時に勝利し、クルー勝利には参加しない。タスクは持たず、停電・通信妨害は修理できない。初期仕様ではベント・インポスター視界・インポスター識別を付与しない。

能力ボタンで認識を待機し、確定した単語一つを認識した時点の自分の足元に設置する。文字自体を灰色・太字・縁取り・厚みのある石文字として並べ、1文字あたりのセル幅を一定にする。例えば「ねこ」は2セル、「インポスター」は6セル。物理判定は単語全体を囲む一つの長方形とし、文字の穴や隙間は通り抜けられない。

## 初期設定

β25の変更（2026-11-29）：認識結果の確認画面・再録音操作を廃止し、認識結果が届いた時点の足元に一度だけ自動設置する。対応するベタクル3.2.72では、共有モデルも発声後の約350msの区切りで認識を始め、設定した録音時間の満了を待たない。設定時間は録音の上限として使う。早期の認識で有効な単語を得られなければ、上限まで次の発声を試せる。認識失敗後の再使用クールタイムは0.5秒。会議・死亡等で中断した要求や重複結果は拒否する。

検証：NoS 108スクリプトのコンパイル（エラー・警告0）、単語検証・即時設置・期限・重複・中断のテスト、通常版／Tauri互換経路の早期送信・無効結果後の再試行・送信先検証、.NET認識テストを通過。Tauri本体でもテスト音声を使い、録音上限前の送信・空結果後の再試行・成功後の重複抑止を確認した。変更後の物理マイク・複数端末の実ゲーム確認は未実施。

| 設定 | 初期値 | 範囲 |
| --- | --- | --- |
| クールダウン | 25秒 | 5〜120秒 |
| 単語待ち | 5秒 | 1〜10秒 |
| 石の持続 | 15秒 | 5〜60秒 |
| 最大文字数 | 8文字 | 1〜12文字 |
| 1文字あたりの幅 | 0.45 | 0.2〜0.8ゲーム単位 |
| 同時設置数 | 2個 | 1〜5個／能力保持者 |

本人・インポスターを含む生存者全員を塞ぐ。幽霊は通過できる。設置時に石に重なっていたローカルプレイヤーには、一度外へ出るまで衝突を免除する。同時上限を超えた場合は最も古い石を撤去する。時間切れ、会議開始、試合終了、役職解除、設置者の切断で撤去する。設置者の死亡だけでは既存の石は消さず、認識待機は中断する。

## 音声連携

既存のプロトコル2に `kind: stone` と `maxCharacters` を追加。待機前はrequest=0として準備状態を通知し、ボタン押下後の要求番号・期限を同期する。PC通常版・Lite版・.NET版は自分のマイクを認識し、Web／モバイルと確認できた参加者だけホストが受信音声を認識する。Web／モバイル自身に認識器を追加しない。古いPC版をホストで二重認識するフォールバックは行わない。

Voskの単語タイミング付き確定結果 `result[].word` から、助詞・一部のつなぎ言葉を除いて最初の有効な単語を選ぶ。全文や途中認識を石に変換しない。認識信頼度0.55未満、文字数超過、タグ・制御文字・空白・記号のある候補は除外する。長い単語を途中で切り詰めて別の単語にはしない。モデルの単語境界と表記には誤認識がある。日本語モデルを利用する。

認識した単語のみUTF-8 Base64で既存のローカルUDPブリッジへ渡す。要求番号・期限・セッショントークン・送信者・最大文字数を検証し、一要求につき一度だけ設置RPCを送る。アドオンは単語・現在地付近の座標を再検証して全員に同じ石を生成する。録音ファイルや全文の認識履歴は保存しない。更新したPC／.NETベタクルとアドオンの両方が必要。

2026-11-10にNoSの1人フリープレイで、発声なしの設置・石文字の描画、文字数に比例した幅、時間切れ、不正単語・二重送信の拒否、設置者死亡時の石の維持と衝突免除フラグを確認した。実マイクの認識精度、生存者・幽霊での実通行、ハシゴ・ドア付近の衝突、複数端末での同期は未確認。[検証結果](testing/2026-11-10/README.md)を参照。
