# ボイスジャミンガー

インポスター陣営。通常のキル・ベント・サボタージュは通常どおり使用できます。

## 対象への妨害

通常の近距離追跡と壁判定を使い、近くの生存者へ妨害を仕込みます。クールダウンは0～120秒、初期値25秒です。再使用すると、次の会議の対象を最後に選んだ相手へ上書きします。

設定で「強制ミュート」または「ローパス」を選びます。初期値は強制ミュートです。対象の声だけに作用し、次の会議が終わると解除されます。以後の会議へ持ち越しません。対象が死亡・切断した場合は適用しません。

強制ミュートは音声送信と受信側の両方で制御します。本人の手動ミュート設定は書き換えず、解除後も元の設定を尊重します。ローパスは1.2 kHzのフィルターをかけます。

## 会議中の全体ピッチ変更

生存中、会議画面左上の能力ボタンを使用できます。本人を含む全員の声のピッチを話者ごとに引き直し、全受信者に同じピッチで聞こえるように同期します。通常の幽霊との会話制限・ミュート・音量設定を維持します。

効果時間は1～120秒、初期値10秒。設定時間が経過するか会議が終了すると元に戻ります。残り回数があれば効果中にも再使用でき、ピッチを引き直して効果時間を再開始します。会議ボタンには残り使用回数と効果の残り秒数を表示します。

使用回数は試合全体で0～10回、初期値2回。0回は無制限です。次の会議で回復しません。強制ミュートされた対象はピッチ変更中も聞こえません。

複数のボイスジャミンガーがいる場合、対象への妨害は併用し、同じ対象への強制ミュートをローパスより優先します。全体ピッチは最後の発動を優先します。先に発動した効果がまだ時間内であれば、後の効果終了時に再び有効になります。

## 実装・確認

アドオンはゲームRPCで発動を同期し、各ゲームプロセスの`voice-jamming-<PID>.json`を通してベタクルへ通知します。会議終了・ゲーム終了・役職解除ではデータを削除し、ベタクルはプロセス違い・不正データ・1秒を超える古い通知を拒否します。

タヌキ丼0.1.0-β14で追加しました。PC通常版・Lite版3.2.38、Web・モバイル版3.30、.NET版3.2.38-net-beta.1以降が必要です。Web・モバイル参加時にはホスト側も対応版へ更新してください。

状態遷移・効果時間・対象別の音声制御・IPC検証の自動テストと各版のビルド、およびゲーム内の役職説明・設定表示を確認しています。複数人での実際の音声と物理iPhoneでの確認は未実施です。
