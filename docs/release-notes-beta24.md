- ボイスストーンを、ベタクルの共有ローカルモデル（Silero VAD＋SenseVoice）による音声認識に対応させました。設定時間の録音後に認識し、結果を確認して設置・再録音・取消できます。モデル未準備時は従来方式を使用します。

NoSコンパイルと、認識結果確認・再録音・設置・取消・期限・描画の自動テストを実施しています。物理マイク・多人数での実ゲーム検証は含みません。
