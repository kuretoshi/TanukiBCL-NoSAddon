タヌキ丼 0.1.0-β20 / Build 59

- 新モディファイア「bitキャラクター」を追加しました。2→4→8→16→32→64bit風へ見た目と声が進化し、最後は本人の元の衣装と通常音声に戻ります。
- 各段階の継続時間は5〜180秒（初期値各30秒）。会議中は時間を止め、声は通常に戻します。
- 2bitは白黒4階調、4〜64bitはプレイヤーの選択色に追従します。通常・歩行8コマ・上り2コマ・下り専用・ベントの画像を用意しました。
- ヒーロー変身衣装を優先し、解除後は現在のbit段階へ戻します。
