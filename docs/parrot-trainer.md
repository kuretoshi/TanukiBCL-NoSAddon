# オウムトレーナー（β19）

クルーメイト役職。NoSのマッドメイトへの配役にも対応する。

## 能力と設定

能力ボタン「オウムを設置」で、自分の足元にオウムを置く。設置されたオウムは全員に見える。

| 設定 | 範囲 | 初期値 |
| --- | --- | --- |
| オウムの最大設置数 | 1～5 | 2 |
| 1件あたりの録音秒数 | 0.5～5秒、0.5秒刻み | 1.5秒 |
| 設置クールダウン | 0～120秒、5秒刻み | 15秒 |
| 声を聞く・届ける範囲 | 1～10、0.5刻み | 3.5 |

近くの生存者が話すと、1人分の声を設定された秒数だけ録音する。設置者本人の声も対象。
録音時間は設置時にオウムごとに確定し、録音の完了判定・再生時間・再録音の間隔にも反映する。
オウムごとに完成済みの録音を最新5件まで記憶し、6件目から古い順に入れ替える。
同時に複数人が話す場合は、ホストが最初に検知した1人を録音する。同じオウムの録音は重複しない。

生存者が範囲へ入り直すと、記憶した録音をランダムに1件再生する。最初は録音のみ。
範囲内に居続けても繰り返さない。境界での連続発動を避けるため、範囲からさらに0.5以上離れると退出と扱う。
再生中に別の人が入っても重ねて再生しない。再生音の発生源はオウムの位置。

壁の向こうや範囲外の声、幽霊の声、非公開無線の送話を録音しない。
入力はマイク・受信した相手の元音声から取得し、オウムの再生出力を録音入力へ接続しない。
ミュート・受信停止・通信妨害の通話制限を維持する。スピーカーからマイクへの物理的な回り込みは通常通話と同じく端末のエコー除去に依存する。

会議では録音と再生を中断し、未完成の録音は破棄する。設置済みのオウムと完成済みの録音は残る。
設置者の死亡・切断・役職解除・ゲーム終了で、その設置者のオウムと録音を破棄する。

## 音声連携

通常版・Lite版の共通ソース、.NET版、Web／モバイル版へ追加した。今回の変更を含む開発版が必要。
既存の開発フォルダーと依存を再利用しており、ソース全体・モデル・依存の新しいコピーは作成していない。

NoSの共通接続へ省略可能な `parrots` チャンネルを追加。最大24人×5羽の120行。
各行は `ownerId, birdId, x, y, range, seconds, recordId, sourceId, started, clips, playId, playClip, playStarted` を持つ。
`seconds` が省略された従来の開発版の状態は、1.5秒として受信する。不正な秒数は受信時にも拒否する。
録音と再生の番号はホストが決定し、NoSのRPCで全員へ同期する。
ベタクルはホストだけが共通接続の `parrot` コマンドで録音開始を要求し、アドオン側でも役職・距離・壁・生存・録音重複を検証する。
.NET版は音声処理中に要求をキューへ積み、ゲーム状態更新時に送信する。
.NET版では共通接続の録音・再生状態を100msごとにも確認し、通常のメモリ読み取り間隔による録音開始の遅れを抑える。

各端末が既存の受信音声から同じ話者を録音し、ホストが選んだ同じ録音番号を再生する。
音声用サーバー・DB・新しい音声送信経路・録音ファイルは追加しない。
音声はモノラル16kHz、1件0.5～5秒（初期値1.5秒）。完成済み5件＋録音中1件の上限があり、メモリ内だけで保持する。
設置されていない場合、Web Audio側の追加録音ノードは作らない／撤去する。

Web／モバイル版には、PCまたは.NETホストの `nosParrots` と `nosVoiceFrameTime` を渡す。
スマートフォン自身の時計には依存しない。途中接続・切断中の過去音声は復元しないため、その部分は聞こえない。
旧アドオンで `parrots` が省略されている場合は空状態と扱い、既存役職の接続互換性を維持する。

## 確認状況（2026-11-10）

設置するオウムと能力ボタンは `addon/Resources/Parrot.png` の透過スプライトを共用する。アモアスのペットに馴染む太い輪郭、丸い体、シンプルな目と陰影、曲がったくちばしのデザインに更新した。[制作プロンプト](design/parrot-sprite.md)。ゲーム用画像は256×256で、テクスチャとスプライトは1つを共用する。

新しいスプライトの読み込み、設置時の表示と能力ボタンの表示をNoS上で確認済み。[設置状態の実ゲーム画像](testing/2026-11-10/parrot-cute-placed-game.png)。

- NoSの93ソースをコンパイルし、エラー・警告なし。
- 設置上限、クールダウン、録音の重複拒否、最新5件の入れ替え、再進入、会議、撤去のテスト。
- 録音0.5・1.5・3・5秒で、録音完了・音声バッファ・再生末尾・途中からの再生を検証。設置数1・5羽の上限も検証。
- PC／Lite・Web／モバイル・.NETでテスト用PCMを録音して再生し、範囲、ミュート、会議、後始末を検証。
- 実際のアドオンTCPサーバー2プロセスとPC／.NETクライアントで、新チャンネルと録音開始要求の疎通を確認。
- PC・Web／モバイルの型チェック、.NETのビルドを確認。
- 今回の追加・変更部分の制御ネストは3以下。.NET全体の検査には、変更していない `ClientSettingsStore.Load` の既存の深さ4が1件残る。
- NoSの1人フリープレイで、2羽の設置と残数表示、テスト要求による1.5秒の録音処理完了、6回後に最新5件を保持、役職変更時の撤去を確認。実マイク音声・再進入による実再生・複数端末間の聴感とタイミングは未確認。
- β19の公開前に開発版をゲームへ配置して検証した。[検証結果](testing/2026-11-10/README.md)を参照。
