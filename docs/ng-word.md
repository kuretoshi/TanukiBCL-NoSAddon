# NGワードと音声認識の分担（0.1.0-β16）

PC通常版・Lite版・.NET版は各自のマイクを自分のPCで認識する。ホストは自分のマイクと、Web／モバイルと確認できた参加者の受信音声だけを認識する。この分担はNGワードとヒーローの「変身」で共通。参加方法が不明な音声をPCと推測してホストへ回すことはしない。

同じプレイヤーが両能力を持つ場合も認識器は一つにまとめる。日本語モデルはプロセス内で共用し、対象者がいない端末では読み込みを始めない。判定結果だけをローカルのゲームへ渡し、変身・死亡はアドオンのRPCで同期する。一般の文字起こしや録音を保存・アップロードしない。

## リストと配布

初回起動時、ゲームフォルダの `TanukiBCL/NGWords.txt` が存在しなければ[テンプレート](../addon/Resources/NGWords.template.txt)をコピーする。既存ファイルは上書きしない。UTF-8で一行に一語を記載する。`#`で始まる行はコメント。必要なら `表示名|読み方|別の読み方` を指定できる。

```text
インポスター|いんぽすたー
タスク|たすく
投票|とうひょう
```

ロビー設定のNGワードで「全参加者へNGワードを割り当てる」をオンにすると、試合開始時にホストのファイルを読み、全陣営の参加者へモディファイアとワードをランダムに割り当てる。通常の陣営別割当数はこの全員配布に使用しない。初期状態はオフ。リストのワード数が参加者数以上なら表示名が重複しないよう配り、不足時だけ循環して重複させる。ファイルを途中で編集しても進行中の試合には反映しない。

各プレイヤーの画面上部に自分のワードと認識状態を表示する。本人のワードを含む確定認識結果を受け取ると本人が自殺する。途中結果では死亡させない。会議中の判定は設定で切り替え可能（初期値オン）。ミュート・未接続・死亡・試合終了中は新しい発言を判定しない。リストは1～256語、各表記2～32文字、読み方は二つまで。空リストや不正な項目は受け付けない。

## 互換性と検証

分担の判別には参加者の更新版ベタクルが送る参加方法を使う。古いPC版をホスト認識へ自動で戻すことはしない。古いWeb版など、参加方法を確認できない場合は認識準備中・未接続と表示する。音声認識連携のローカルプロトコルは2へ更新しているため、アドオンとベタクルを揃える必要がある。

PC版ではホスト／非ホストの認識対象、同一プレイヤーの認識器共用、参加方法の期限切れ、重複結果、ミュート前の音声の破棄、試合退出の自動テストを通過。.NET版の分担・表記揺れ・連携プロトコルの自己テストとビルド、Web／モバイル版のビルドと210件のテストも通過した。

NoSのフリープレイで全員配布、ワードと認識状態の表示、誤った判定番号の拒否を確認。制御した判定結果を使い、変身とNGワードの併用、およびNGワードによる死亡処理まで確認した。この確認では実マイクの単語認識は試していない。複数端末間の実音声、人数を増やした負荷、誤認識率は別途確認が必要。テスト用に変更したゲーム設定は元に戻している。
