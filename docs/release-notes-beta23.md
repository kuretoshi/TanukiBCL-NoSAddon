タヌキ丼 0.1.0-β23 / Build 62

- ボイスストーンで、認識結果の確認画面が開かず設置できない不具合を修正しました。再録音・キャンセルも正常に呼び出せるようにしました。

- 壁に耳ありは、耳に近づくと能力の「使用」ボタンが表示される方式へ変更しました。使用中は「解除」になります。
- スーパーヒーロー・イーヴィルヒーローの歩行、マント、はしご上り下り、ジップラインの姿勢を調整しました。
- bitキャラクターにジップライン専用の姿勢を追加し、使用時に巨大化する不具合を修正しました。

ベタクルは通常版・Lite版3.2.67、Tauri版3.2.67-tauri-beta.1、.NET版3.2.67-net-beta.1を推奨します。Web・モバイル版は3.63を継続します。
