# スーパーヒーロー／イーヴィルヒーロー（0.1.0-β16）

スーパーヒーローはクルーメイト陣営、イーヴィルヒーローはインポスター陣営です。どちらも変身前はキルできません。

能力ボタンを押すと発声待機に入り、待機時間内に「変身」と発声すると変身します。PC通常版・Lite版・.NET版は各自のベタクルの日本語Voskモデルで自分のマイクを認識し、Web・モバイル参加者だけホストが受信音声を認識します。外部APIへ音声を送信しません。NGワードも同じ分担を使います（[詳細](ng-word.md)）。

## 設定

両役職で個別に設定できます。

| 設定 | 初期値 | 範囲 |
| --- | --- | --- |
| 変身時間 | 10秒 | 1～120秒 |
| 変身ボタンのクールダウン | 30秒 | 0～120秒（5秒刻み） |
| 変身中のキルクールダウン | 2.5秒 | 0～30秒（2.5秒刻み） |
| 発声待機時間 | 5秒 | 1～15秒 |
| 変身中にプレイヤー名を隠す | オフ | オン／オフ |

声はボタン使用後の音声から認識します。ミュート中・未接続・期限切れの音声では発動しません。ボタン使用前の声は発動条件に含めません。同音の「返信」と認識される場合は、発言全体がその単語のみのときに限って受け付けます。担当端末の音声認識が準備できるまで変身ボタンは使用できません。

変身ボタンは試合開始時にも設定値のクールダウンがあります。変身成功後は、変身終了時から設定した通常のクールダウンを開始します。発声待機中に「変身」を認識できずタイムアウトした場合は、1秒固定のクールダウンで再試行できます。通常のクールダウンを0秒に設定していても、失敗時は1秒です。会議・死亡などによる中断は通常のクールダウンを使用します。発声待機中・変身中は残り秒数を表示します。ボタンを押しただけの待機中には、無敵やキル能力はありません。

「変身中にプレイヤー名を隠す」は両ヒーローのロビー設定で個別に変更できます。オンの場合、変身成功から効果終了まで頭上の名前表示を非表示にします。発声待機中は隠しません。NoSの名前非表示属性を使用し、変身終了・会議・死亡・試合終了・役職解除で、この能力が付けた属性だけを解除します。名前やアカウント情報そのものは変更しません。

## 変身とキル

変身ボタンは専用衣装の姿を描いた透過アイコンを使用します。スーパーヒーローは青いスーツ・赤マントと金色の光、イーヴィルヒーローは黒紫のスーツ・紫マントと闇のエネルギーで区別します。素材と生成指示は [hero-transform-icons](design/hero-transform-icons/README.md) に保存しています。

変身中は通常の帽子・服・バイザー等を一時的に隠し、全身を専用衣装に切り替えます。スーパーヒーローは青いスーツと赤いマント、イーヴィルヒーローは黒紫のスーツと紫のマントです。NoSのMoreCosmicへ通常・歩行・梯子上昇・梯子下降の画像を登録し、左右反転とアニメーション状態に応じた画像選択はNoSに任せます。歩行は8コマをNoSの歩行周期に同期し、衣装の取り付け位置を立ち姿と同じ高さへ固定し、全身が跳ねるのを抑えます。停止中と梯子用の姿勢は静止画です。スーパーヒーローは白・金の光、イーヴィルヒーローは黒・紫の闇を纏います。変身時に広がる演出と、効果時間中の揺らめくオーラがあります。変身成功時に、スーパーヒーローは利用者提供の「シャキーン3」、イーヴィルヒーローは「nc214370_【効果音】魔法_闇_ﾌﾞｰンンン」が一度鳴ります。SE音量設定と距離による減衰に従い、不可視中は再生しません。視界や通話距離を広げる効果はありません。

スーパーヒーローはクルー役職を狙うと自分だけが誤射で死亡し、相手は生存します。インポスター・第三陣営はキルできます。イーヴィルヒーローは通常のインポスター式で、味方インポスターは対象外、クルーへの誤射はありません。ベント・サボタージュはインポスターの通常仕様を維持します。

変身中のキル無効化はホスト側のキル判定で行い、全クライアントへ変身状態をRPCで同期します。スーパーヒーローはイーヴィルヒーローのキルを、イーヴィルヒーローはスーパーヒーローのキルを防げません。自殺・誤射・追放は防ぎません。

時間終了・会議開始・死亡・試合終了・役職解除で変身と演出を解除します。変身が終わると再びキルできなくなります。既存の服装データを書き換えないため、変身解除後は元の服装が維持されます。

## 変身コスチュームと声

スーパーヒーロー／イーヴィルヒーローの変身中は、専用衣装による見た目の変化を理由に声を加工しません。変身待機中にはこの例外を付けず、変身時間終了・会議・死亡・試合終了・役職解除で解除します。

各NoSクライアントがRPCで同期された変身状態を `hero-transforms-<PID>.json` へ出力し、ベタクルはPIDと1秒以内の更新時刻を検証して読み込みます。PC通常版・Lite版・.NET版のゲーム状態へ追加し、ホスト経由のWeb／モバイル版にも中継します。Web／モバイル版は自身の時計でホストの更新時刻を判定せず、ホストが検証したゲーム状態を使います。

この例外は変身中の対象者だけに適用します。ボイスジャミンガーなど別の能力による音声妨害は、それぞれの通常ルールで判定します。専用衣装の原本と配置基準は `docs/design/hero-costumes-v2` にまとめています。現在の開発版は `addon/MoreCosmic` の定義と画像を使用します。

対応版はPC通常版・Lite版3.2.47、.NET版3.2.47-net-beta.1、Web・モバイル版3.39以降です。PC通常版の実マイクで「変身」の認識と変身状態への移行を確認し、スーパーヒーローの指定SEが聞こえることも利用者が確認しています。新しい衣装の開発版ZIPをNoSへ導入し、認識成功のテスト信号を使って両ヒーローの全身衣装・光／闇のオーラと、時間終了後の元の帽子・服・バイザーの復元を確認しました。エアシップで両ヒーローの歩行と梯子の上昇・下降、昇降後の通常姿勢への復帰も確認済みです。歩行は8コマが選択され、取り付け位置の高さは一定でした。複数人での相互キル・他クライアントからの表示は引き続き実機確認が必要です。
