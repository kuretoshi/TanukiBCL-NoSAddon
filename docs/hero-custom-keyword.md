# ヒーローの変身ワード（β17）

各プレイヤーが自分のNoSゲーム画面の「設定 → NoS → 自分の変身ワード」を開き、スーパーヒーロー／イーヴィルヒーローを選んで変身ワードと任意の読み方を保存する。ホスト専用・ロビー共通の設定にはしない。初期値は両役職とも「変身」、読み方は空欄。2～32文字の言葉に対応する。たとえば本人Aは「蒸着」「じょうちゃく」、本人Bは「闇落ち」「やみおち」を指定できる。

空欄や1文字、33文字以上、記号だけ、改行・制御文字・不正なUnicode・`< > |`を含む入力は保存しない。読み方は空欄で解除できる。キャンセル時は変更しない。ホスト以外も、タイトル・ロビー・試合中の設定画面から変更できる。保存後、次に変身ボタンを押したときから使用する。発声待機中のワードを途中で差し替えない。

言葉はNoSのローカル保存機能を使い、`NebulaOnTheShip/TanukiHeroPreferences.dat`に各端末の個人設定として保持する。部屋の共有設定・プリセットに含めず、ホストのワードで他プレイヤーを上書きしない。変身ボタンを押した本人がその時点の個人設定をアドオンRPC `TanukiHeroSpeechArmV2`に載せる。受信側も長さ・内容を検証して、そのプレイヤーの発声待機にだけ適用する。待機中のボタンに実際の変身ワードを表示する。設定画面では問い合わせボタンと「自分の変身ワード」ボタンを同じ下部の行に並べる。

選択画面と入力画面はUIレイヤーを描画するカメラの子に固定し、ワールド原点や登録済みの設定ダイアログの子には置かない。NoSが各ダイアログに設定するZ座標を二重に加算しないためで、ロビー／試合中のカメラ移動によるずれ・揺れを防ぐ。文字とボタンにはマスクなしのフォントを使い、背後の設定一覧のマスクに切り取られないようにする。タイトル、ロビー、エアシップのフリープレイ中で選択・入力画面の中央表示、時間経過後の位置、説明文・ボタン枠の欠け、保存・キャンセルの動作を確認した。

音声認識の分担はそのまま。PC通常版・Lite版・.NET版は本人のPCで認識し、Web・モバイルで音声参加する人はホスト側で認識する。音声参加方法にかかわらず、変身ワードの入力は各自のNoSゲーム画面で行う。各端末のアドオンは、プレイヤーごとに受信したワードを既存のローカル連携プロトコル2の`words`に渡す。新しいベタクルは、そのプレイヤーのワードを使って認識する。カタカナ・ひらがな、空白、句読点、全角英数字は既存の正規化を使う。初期ワード「変身」のみ、従来の仮名表記と確定結果「返信」の補正も維持する。任意ワードに変更した場合は「変身」へ自動で戻さない。

古いアドオンの空の`words`は新しいベタクルでも従来の「変身」で認識する。新しい任意ワードを使う参加者側のPC／.NET版と、Web・モバイル参加者を認識するホストのベタクルは、この変更を含む版が必要。Web・モバイル側に認識器は追加しない。日本語モデル自体は変更せず、珍しい言葉の認識率は実マイクで確認する。

イーヴィルヒーローには「変身前もキルできる」を追加。初期値はオフ。オンの場合、変身前も通常のインポスター式キルができる。変身しない間は無敵にならず、クルーへの誤射もない。スーパーヒーローは従来どおり変身中だけキルできる。キルクールダウンは変身前後で同じボタンのタイマーを使い、変身によってリセットしない。

任意ワードの認識にはPC通常版・Lite版3.2.49以降、.NET版3.2.49-net-beta.1以降を使用する。Web・モバイル参加者の場合はホスト側を更新する。
