# インタビュアー

クルーメイト陣営の役職。自分の声と、その時点で視界内にいる生存者の声を同時に録音し、会議中に全員へ再生する。

- 録音時間：1〜30秒、初期値5秒。
- 録音クールダウン：0〜120秒、初期値20秒。録音終了後から進む。
- 会議ごとの再生可能回数：1〜10回または無制限、初期値は無制限。再生開始時に1回消費し、会議ごとにリセットする。録音を持ち越した場合も新しい会議の回数を使う。
- 「通信妨害中は能力を使用不可にする」：初期値オフ。オンの場合、通信妨害中は録音を開始できない。録音途中に発生した場合はそこまでを保存し、通常のクールダウンに入る。修復後に自動で録音を再開しない。会議中の再生にはこの設定を適用しない。
- 壁・実際の視界半径・透明化・潜伏を確認し、録音中に対象を更新する。幽霊は録音対象外。
- 再録音で最新1件を上書きする。録音途中で会議開始・死亡した場合は、その時点までの部分を保存する。
- 会議画面左上に本人用のボイスレコーダーボタンを表示する。本人が生存しており録音があるときに再生可能。
- 再生は会議中だけ。生存者・幽霊・本人を含む全員の対応ベタクルで再生し、会議終了で停止する。
- 同じ録音は会議をまたいで保持できる。再生終了後、残り回数があれば再び再生可能。ボタンに残り回数を表示し、使い切ると「再生回数なし」になる。
- マイクのミュート、受信側のミュートと全体音量を尊重する。
- 録音音声は対応ベタクルの各端末のメモリにのみ保持する。試合終了・役職解除・再録音で破棄する。
- 録音時に未接続だった端末には過去の音声を転送しない。再接続後は次の録音から参加する。
- 複数インタビュアーの録音は別々に保持する。
