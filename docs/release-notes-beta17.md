# タヌキ丼 0.1.0-β17

NGワードに、ゲーム開始時に全員がワードを入力する方式を追加しました。役職紹介のあと、黒い背景の中央に入力画面を表示します。確定すると待機画面へ切り替わり、全員の確定後にワードをランダムに配布してゲームを開始します。自分が投稿したワードは自分に配られません。

「NGワードの割り当て人数」で、全員または1〜24人を指定できます。配布人数を減らしても、入力方式では全員がワードを投稿します。従来のファイル方式にも人数指定を適用します。

入力方式は初期状態ではオフです。「NGワードを割り当てる」と「ゲーム開始時に全員がNGワードを入力する」をオンにして使用してください。設定の「入力画面を確認」から入力・待機画面を試せます。確認モードでは送信・配布しません。

- 配布ZIP: `TanukiBCL-NoSAddon.zip`
- 全参加者のアドオンを同じ版に更新してください。任意の変身ワードを使う場合はPC通常版・Lite版3.2.49以降、.NET版3.2.49-net-beta.1以降を使用してください。Web・モバイル参加者はホスト側のベタクルを更新してください。
- 検証: NoSスクリプトのコンパイル、配布ロジックの自動テスト（2〜24人・各100乱数・人数指定・切断・入力検証）、ローカルゲーム内の入力→待機の表示確認。
- 複数端末での開始・全員確定・待機解除、および実音声を使った新方式の通し確認は未検証です。

自分のNGワードを隠して他の人の名前の上に表示する設定を追加しました。会議中は投票プレートの名前の上に表示します。初期値はオフです。

「設定 → NoS → 自分の変身ワード」で、ヒーローごとに自分専用の変身ワードと任意の読み方を設定できます。保存した内容は次に変身ボタンを押したときから反映します。

NGワードリストの参照ファイル選択、テンプレート保存、現在のリスト保存を追加しました。ロビー・フリープレイのホスト設定から操作できます。

イーヴィルヒーローに「変身前もキルできる」設定を追加しました（初期値オフ）。オンにすると変身前も通常のインポスター式キルを使えます。変身前の無敵は付与しません。
