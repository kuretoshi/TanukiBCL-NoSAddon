# 通常クルー体格のヒーローコスチューム

2026-11-21 開発版。スーパーヒーローとイーヴィルヒーローの胴体・短い足・バックパックを通常クルー基準で描き直した。青と金・赤マント、および黒紫・紫マントの配色は維持する。大きなヘルメット、長いブーツ、人間のような胴体は使用しない。

制作には組み込み image_gen を使用。選定した透過原画は `super-atlas.png` と `evil-atlas.png`、生成・編集指示全文と参照ファイルは `prompts.json` に記録する。4列×6行の原画から、通常1・歩行12・上り2・下り1・ベント1・ジップライン4コマを機械的に分割・等比縮小・位置合わせする。最後の3セルは未使用。

再出力は `py -3.12 scripts/export-native-hero-costumes.py`。既存の `export-hero-motion.py` も新しいエクスポーターへ転送する。通常は通常クルー画像の頭頂Y=116、足元Y=308に合わせ、通常スーパーヒーローの全体の高さは193px（基準192px、境界の半透明ピクセル込み）。全体サイズや足元をコマごとに自動フィットさせない。歩行では共通倍率と既存の頭部アンカーを使い、12コマでマントをなびかせる。はしごの上りと下りは別ポーズ。ジップラインは握り位置(220,55)を既存の実行時処理に渡す。実際の配置値は `alignment.json`。

`comparison.png` は通常クルー／公開β23／新デザイン／新しい上りの比較。`walk.gif`、`climb-up.gif`、`zipline.gif` は素材プレビューでありゲーム画面のキャプチャではない。

検証済み：画像の透過・切れ・寸法・足元、MoreCosmic定義、既存の歩行・はしご・ベント・ジップライン復元テスト。ゲーム内での実表示とマイクを使った確認は未実施。公開・インストール済みZIPはまだ置き換えていない。
