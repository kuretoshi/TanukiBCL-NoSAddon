# bitキャラクターのジップライン専用ポーズ

2026-11-19の開発変更。元のファングルを基準に、両足を前に曲げて体を後ろへ傾けた、座るような専用乗車ポーズへ変更した。アモアスと同様に腕を長く描かず、握り手は体から離す。手・体・足を1枚のポーズとして扱う。以前の「通常の立ち姿と外部の手を別々にピクセル化する」実装・仮配置プレビューと、腕を伸ばして足を下へ垂らす誤った素材は使わない。ヒーロー2種も同じ座り姿勢へ修正した。

組み込み `image_gen` で通常クルー用の4コマを制作した。原本は [source/zipline.png](source/zipline.png)。現在の修正指示は [seated-zipline-prompts.json](../hero-costumes-v2/seated-zipline-prompts.json)、以前の初稿指示は [zipline-prompt.json](zipline-prompt.json)。ヒーローと通常クルーの識別用デザインを保持し、元のファングルの座り姿勢へ修正した。bit用には帽子・マント・ベルト・ヒーロー衣装を含めない。

`py -3.12 scripts/export-bit-zipline.py` が共通倍率で位置を揃え、赤＝体、青＝影、緑＝バイザー、黒＝輪郭の適応色マスクへ変換する。共有の `scripts/zipline_layout.py` は体と握り手が別のアルファ領域であることを確認し、切れない倍率で握り位置（220,55）へ配置する。2/4/8/16/32bitのピクセル単位は16/12/8/6/3px相当。2・4bitでも手と頭がつながって長い腕に見えないよう、粗いグリッド1ピクセル分の透明な隙間を保つ。各段階のゲーム素材は `addon/Resources/BitCharacter/Zipline{bits}.png`（1200×375、300×375の4コマ、RGBA透過）。倍率と掌の座標は [zipline-alignment.json](zipline-alignment.json)。

`BitCharacterZiplineVisual` は実際の乗車者の手を検出し、ヒーローと同じローダー・掌の位置合わせを使う。専用描画中は通常bit本体を止め、元の手を隠す。パレット・透明度・マスク・描画順はそのプレイヤーの本体へ追従する。2bitだけ4階調の白黒を設定し、元のプレイヤーカラーや共有マテリアルは変更しない。乗車終了・キャンセル・死亡・マップ変更・段階変更・ヒーロー割り込みで専用表示を破棄し、元の手の描画フラグと通常bit表示へ戻す。

巨大化の修正：専用ポーズの親はプレイヤー本体のルートではなく、通常bit描画と同じ `currentBodySprite.BodySprite.transform` にする。これにより見た目用の縮尺（通常0.35）と途中のサイズ変更を引き継ぐ。ローカル倍率は1を保ち、握り位置だけをワールド座標へ合わせる。固定の0.35倍を追加せず、役職などによる本体サイズの変更にも追従する。実際のゲームに近い階層を持つ自動テストで、修正前の取り付け先では失敗し、修正後に5段階すべてで描画倍率が通常本体と一致することを確認した。

`py -3.12 scripts/preview-bit-zipline.py` はゲーム用の実素材を使って [比較PNG](zipline-preview.png) と [4コマGIF](zipline-preview.gif) を更新する。左右方向と赤の選択色の例を示す素材プレビューで、ゲーム画面のキャプチャではない。

実コードの自動テストで、全5段階の全身表示・通常本体との排他・握り位置・4コマ・左右反転・パレット・透明度・マスク・描画順・同段階の素材共有・ヒーロー優先と復帰・乗車終了／キャンセル／死亡／段階変更時の復元を確認する。NoS実参照のコンパイルも行う。専用ポーズの実ゲーム表示確認は未実施。
